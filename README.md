# Glowing Neon Red Rose

Interactive single-page canvas artwork with neon color themes, animation controls, ember particles, and PNG export.

## Deploy on Vercel

Use these project settings:

- Framework Preset: `Other`
- Root Directory: `.`
- Build Command: leave blank
- Output Directory: `.`
- Install Command: leave blank
- Node.js Version: default

The included `vercel.json` maps the site root to the HTML entry point.
